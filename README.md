 Recipe App
A modern and responsive Recipe Search App built using HTML, CSS, and JavaScript that allows users to search for delicious recipes using the TheMealDB API.
Users can search for meals, explore recipe categories, and view beautifully designed recipe cards instantly.

 Features
 Search recipes dynamically
 Fetch real recipe data from API
 Fully responsive design
 Clean and modern UI
 Recipe cards with images
 Displays recipe origin and category
 Fast and lightweight application

 Tech Stack
HTML5
CSS3
JavaScript (Vanilla JS)
TheMealDB API
